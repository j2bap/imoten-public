# 0003: Name the fork Imoten

## Context

The repository started as `pstack-for-codex`. That name describes its source and runtime, but it does not give the fork its own clear identity. The first personal GitHub release gives us a safe point to set one name before other users depend on the old package IDs.

## Decision

Name the owned distribution, plugin, package, and repository `Imoten`. Keep `poteto-mode` as the main workflow name. Keep exact pstack source paths, source hashes, compatibility records, and inherited skill names when they describe upstream pstack.

Credit both source layers: Lauren Tan's pstack project and Aqua-123's `pstack-for-codex` fork.

## Reason

Imoten is short and distinct. The name refers to sweet-potato tempura and fits Poteto Mode. Keeping source records unchanged preserves a clear and verifiable history.
